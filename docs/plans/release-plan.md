# リリースの検討メモ

2026-09-29時点の検討内容。位置づけは`CLAUDE.md`の「キャッチアップの状況と方針」、日程は`docs/plans/roadmap.md`を参照。

## 位置づけ

- 上長の指示ではない自主的な目標で、納期は無い。意味はリリース作業を一通り体験することと、
  キャッチアップ期間の成果の保証
- 本案件の要件定義に向けた知識(バックエンド・API設計・認証)より優先度は低い
- 10月中は下記の「10月中に試すこと」だけを本線と並行して行い、残りは11月以降に個人で続ける
- リリース作業は未経験。詰まったら先輩社員にチャットで聞く(まとめて相談したいことは月1の帰社日へ)

## 方針

- リモート同期を使わず、ローカルのみで完結させる(維持費を出さないため)
- 個人名義ならAndroidのみで無料公開する。iOSはApple Developer Programの年会費(99 USD/年)が
  かかるため対象外
- 会社名義で出す可能性もある。その場合は費用を会社に出してもらえるか確認する。実績になるなら
  多少のコストは許容する

## 10月中に試すこと

- [ ] 個人名義での公開の可否を上長に確認する(業務のキャッチアップとして作ったもののため、
      コードの権利の扱いも含めて)。会社名義にするかもここで決める
- [ ] Google Play Consoleへの登録(個人は25 USD、1回だけ)と本人確認(待ち時間があるので早めに)

      審査待ちが無い)。期限は設けない
